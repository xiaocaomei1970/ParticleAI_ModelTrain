# 项目简介

在基于图片的颗粒粒度分布测量系统中，传统的颗粒分割与提取算法，对颗粒粘连和重叠情况严重的图片，处理效果非常差，基本无法把粘连/重叠的颗粒准确地分割和提取出来，只能把多个粘连的颗粒当成一个颗粒来处理，必须依靠后续人工审核来保证粒度分布测量的准确性，工作量巨大。
本项目的目标是：训练一个分割和提取图片里面颗粒的AI模型，一方面提高粘连颗粒分割和提取的准确性，减少后续人工审核的工作量；另外一方面，提升推理性能。
